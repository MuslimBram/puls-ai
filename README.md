# Pulse AI

Pulse AI is an AI Business Operating System for running, automating, and growing a business.

## Runtime

- Frontend: React + Vite
- Hosting: Vercel
- Backend/Auth/Database/Edge Functions: Supabase
- Public domain: https://pulse-bos.com
- Transition domain: https://kohablerjeve.top
- AI: canonical Pulse AI multi-provider router

Production changes are made through reviewed GitHub pull requests.
